# .NET for Android error XA4350

The project-local `Microsoft.Android.BindingGenerator.Semantic` preview
cannot use the selected configuration. `AndroidBindingGenerator` accepts
`Legacy` and `Semantic`; blank uses the workload's original generator.

`Semantic` currently requires an SDK-style `IsBindingProject=true` project
targeting `net11.0-android`, Android workload 37.x, and the package's targets
imported after the Android SDK. Non-Android inner builds are not switched.

Correct the setting/project or use `Legacy`. Do not work around an unsupported
SDK import order by replacing workload task DLLs. This diagnostic belongs to
the experimental package, not an enabled-by-default workload feature.
